# Taschenrechner-f-r-Kommandozeile-mit-Python
Python Taschenrechner für die Kommandozeile. Klein gehalten, macht aber seinen Job.
## Einschränkungen
- Keine Dezimalzahlen
- Keine Klammern / Kettenrechnungen (z.B. `1+2+3` funktioniert nicht)
- Division durch 0 wird nicht abgefangen
## Geplante Verbesserungen in naher Zukunft
- Unterstützung für Dezimalzahlen
- Kettenrechnungen (z.B. `1+2+3`)
- Fehlerbehandlung bei Division durch 0
